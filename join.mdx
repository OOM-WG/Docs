## 交流守则

### 导言

您可以自由地加入本页面所列出的交流渠道，包括 _一人多号加入同一渠道_ 与 _同一人加入多个渠道_

您在任何官方群组内都需要遵守以下内容，此守则在大部分情况下都不会影响到您的言论自由，但仍需注意**不要触碰这些红线**

### 基本能力要求

在官方群组内交流**即视为您有以下基本能力**，**请勿询问**与基本能力有关的内容，本群组不提供任何基本能力的支持

<Expandable title='附注'>
	请在别处**自行学习**这些内容，我们**不歧视**任何低技术人群，但是与之交流会耗费大量时间精力，我们依据现有情况并不能做到这些
</Expandable>

#### 上网能力

您需要有以下基本的上网能力:

- 了解 _链接_、_域名_、_根域名_、_子域名_ 等相关概念
- 认识各大主流**搜索引擎**，能够正常**搜索内容**并**区分广告与有效内容**
- 能够正常判断文本是否为**链接**，能够正常识别掺杂在链接中的**间隔符号**，并能够将其**删除**或**转为正确符号**，并且能够将链接**输入进浏览器内**进行访问
- 能够判断进入哪些网站可能需要**使用代理**或是否存在**检测 IP 纯净度**的可能性，也能考虑到**浏览器兼容性**等问题

#### 玩机能力

如果您将要交流 _root_ 等**玩机相关内容**，请务必保证您有以下基本能力:

- 对 `adb` 与 `fastboot` 有最基本的了解，会使用它们连接设备，并且能够使用 `fastboot` 或 _第三方 Recovery_ 等方式**刷入分区**
- 能够使用 `logcat` 等命令或其他日志抓取软件/模块 **抓取错误日志**
- 了解各种 root 实现方式的**目标分区**，例如针对 _ramdisk_ 的 root 实现，针对 _内核_ 的 root 实现，能够区分 _GKI_ 与 _LKM_ 的区别，了解 `boot` 分区与 `init_boot` 分区的作用
- 能够区分哪些内容需要 _普通权限_/_adb 权限_/_root 权限_，知道 _Xposed 模块_ 与 _Zygisk 模块_ 的使用方法，能够判断一个 `zip` 压缩包是 _普通的压缩包_ 还是 _Android 软件安装包_ 还是 _被二次压缩的安装包_ 或是 _root 模块安装包_ 等

### 名称规范

在官方群组内，_SSU_ 仅能为项目 _ShiroSU_ 的 _简写_ 与 _官方名称_ 之一，_SSUU_ 仅能为项目 _苏柚_ 的 _简写_ 与 _官方名称_ 之一，除非在上下文中有明确说明

### 言论规范

您需要确保您的言论不会涉及以下内容:

- 涉及 _色情低俗_、_暴力恐怖_、_精神污染_、_政治_（适用于 _表情包_）
- _广告_ 或**无意义**的 _推广_
- 对**同类竞品**的 _推广_（除非依据上下文真的有必要这么做）
- **在线游戏**的 _外挂程序_

还需要注意的是，尽量不要在 _**中国大陆**境内平台_ 交流 _代理_ 等相关内容

### 良性发展

为促进良性发展，我们支持提出任何利好的建议，但是我们也有可能依据实际情况予以拒绝，在提出时请确保自身有能够承担**被拒绝**的心理素质

并且请勿对项目的发展提出 _主观_、_片面_ 的不当评价，请依据现实情况与实际体验而进行切实评价

### 结语

当您违反以上规定时，我们可能会对您进行 **警告**/**禁言**/**踢出** 行为，可能不会有 _预示_ 或 _解释_，但不会滥用职权无故处罚
