# 回忆溢出工作组网站组

为利于统一维护，回忆溢出工作组的主要网站均在此处维护

<oom-wg.dev> 使用 [Mintlify](https://www.mintlify.com/) 部署，统一发布文章、项目文档内容

以下项目文档已迁至此处:

- ShiroSU <ssu.oom-wg.dev>
- 苏柚 <suu.oom-wg.dev>

## 本地预览

初始化项目:

```shell
bun i
```

运行本地预览:

```shell
bun dev
```
