## 最初的开始

SSU 开始还是挺有意思的，最初只是 [@ShIroRRen](https://github.com/ShIroRRen) 开发了 `SSUS` 及第一版 Systemless （类似Meta模块），然后出现了一个 idea，要不自己写一个 SU 实现，然后就没有然后了 (hhh...)

<Card title='关于 SUU' type='Info'>
  在 SSU 之前还有 SUU (苏柚)，那时候 [@ShIroRRen](https://github.com/ShIroRRen) 名字还是不是现在的 --
  [@GunRain](https://github.com/ShIroRRen)， 这就涉及到 SUU 包名的一些事情了

SSU 实现并不是一番风顺，看到了很多不看好的评价，`KSU Fork` `PPTSU` `没做好就出来造势` 被质疑，异样的声音，虽然不太理解为什么多是负面评价，以至于后来 [@ShIroRRen](https://github.com/ShIroRRen) 对 SukiSU 敌意非常大，如果没有成果而且虚假造势确实应该被质疑，但 [@Linso](https://github.com/Linso05) 已经探索通方法可行性，虽然后面 [@Linso](https://github.com/Linso05) 确实一直在摆，毕竟谁的时间也不充裕

**然后循环往复的日常**

从 SSU 开始到现在差不多一年多了，现在实现的方式和最初的 [@Linso](https://github.com/Linso05) 预计方案完全不同，目前方案大概是在 [真正的现代 root 方案 —— ShiroSU](https://oom-wg.dev/blog/ssu-nt) 差不多不到 4 个月之前的设想的。再 3 月 8 号这一天推了尝鲜预览，这个节点还是只有 root 授权可以使用。然后一直拖到现在，前端经过我重写之后，和 [@ShIroRRen](https://github.com/ShIroRRen) 后端 API 的设计，逐渐有一点点模样了

<Info>[@ShIroRRen](https://github.com/ShIroRRen) 中途跑去玩异环了，导致模块实现一直延期</Info>
