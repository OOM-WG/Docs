[modify.my.id](https://modify.my.id) 能够修改部分 _匿名标识符_、_唯一标识符_

## 支持范围

### AOSP & Google

- SSAID (Android ID)
- AAID (广告 ID)

### MIUI & JoyUI & HyperOS

- OAID (开放匿名设备标识符)
- VAID (开发者匿名设备标识符)
- Extm ID
- GC ID
- Key ID

### ColorOS & OxygenOS & realmeUI

- Security ID
- OUID (开放匿名设备标识符)
- GUID (设备唯一标识符)
- 百度 ID

### HMS Core (EMUI & MagicUI & HarmonyOS)

- OAID (开放匿名设备标识符)
