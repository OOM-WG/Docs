## 兼容性

ShiroSU 目前作为 **第三方 root 管理器**、**独立 root 实现** 进行双路线开发

<Note>**独立 root 实现** 部分仍在开发中，目前仅可作为 **第三方 root 管理器** 使用</Note>

只要有 root，不管是来自 ShiroSU 自己的，还是来着其他 root 实现的权能，均可在 ShiroSU 使用，
但第三方 root 实现**仍需要逐步支持**才可完整使用

## 拓展软件

[**苏柚** (简称 **SUU**)](/suu) 是 ShiroSU 的拓展软件，不过本质上它们是两个独立软件

苏柚 着重于**更多功能使用**，而不是 ShiroSU 这样着重于**基本的使用体验**

它**不局限于 root**，**普通用户权限**、**adb 权限**、**DeviceOwner 权限** 也可在 苏柚 使用，
同时还有 **Xposed 注入** 功能，
还可以通过 **Windows 版本**来体验更多内容
