## 检查您的设备是否被支持

ShiroSU 仅支持 Android 版本大于等于 `10` 的设备

通常可以在 `设置` → `关于本机` 获取到 Android 版本号，例如:

```properties
# Android 版本
16 | Android 版本更新: 2026-02-01
```

## 修补启动镜像

ShiroSU 提供了一种 Web 修补方案，仅需要将设备的 `init_boot.img` 或 `boot.img` (**优先前者**) 上传, 在资源管理器中找到修补好的镜像

<Card icon='link' horizontal href='https://su.shiror.ren/patch' title='修补镜像'>
  ShiroSU 仅支持系统版本为 **Android 10+** 的设备
</Card>

## 刷入修补完成的镜像

<Danger>在刷入之前请备份原厂镜像，如果设备无法开机，刷写回原厂镜像即可</Danger>

```sh
fastboot flash init_boot <修补后的镜像路径>
```

## 使用

ShiroSU 可以通过 Web 进行管理

在这之前需要获取设备的 `序列号` 作为唯一的密钥，执行以下任意命令即可获取到设备的序列号，或者在 `关于本机` 中找到序列号
(**对于欧加真的高通机型，通常是不准确的，优先使用命令获取**)，大部分机型的序列号为 **16**位*大写字母*&_数字_ 或 **8**位*小写字母*&数字

<CodeGroup>

```powershell Command 1
adb get-serialno
```

```powershell Command 2
adb devices
```

```powershell Command 3
adb shell getprop ro.serialno
```

</CodeGroup>

### 在基本设置中建立与后端的连接

<Card icon='link' horizontal href='https://shirosuutils.pages.dev/settings' title='后端设置'>
  建立与后端的连接
</Card>

- 目标IP: 默认 `127.0.0.1`
- 目标端口: 默认 `5355`
- 鉴权密码: 默认 `序列号` (在无序列号的设备上将回退为 `SSU-PASSWD`)

<Tip>如果在局域网中可以在其他设备上填写对应 IP，也可以使用 adb 进行端口转发 `adb forward tcp:5355 tcp:5355`</Tip>
