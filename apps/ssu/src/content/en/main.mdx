**The ShiroSU Series** is a **series of projects** by **OOM WG**
built to improve the Android tinkering experience, with each project serving a different role around the same goal

> **ShiroSU** is not a single project, but a series made up of multiple projects

Because each project has its own role, use and discuss project names clearly to avoid confusion around the **ShiroSU Series**

<Callout title='Project independence'>
  No project in the **ShiroSU Series** is a fork of a well-known project; every project is developed jointly by members of
  **OOM WG**
</Callout>
