**ShiroSU&trade;** (formerly SakiSU/SakitinSU) is a **project series** created to improve the Android tinkering experience
Each project has a distinct role while sharing the same goal

<data-nosnippet data-nosnippet>

> **ShiroSU** is not a single project, but a series made up of multiple projects
>
> Every project in the series is independently developed by **OOM WG**, never as a branch of a well-known project

</data-nosnippet>

The root mainline of the **ShiroSU Series** consists of [**ShiroSU NewTech**](/newtech) and [**ShiroSU Compat**](/compat), developed primarily for Android root tinkering

[**ShiroSU Utils**](/utils) focuses on Android tinkering across different permission levels, while the remaining projects focus on capabilities for specific scenarios
