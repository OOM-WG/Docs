**ShiroSU Compat** is a **multi-purpose manager** for **multiple root implementations**, providing **more convenient** root management with **one root manager** across different implementations

> [**ShiroSU NT**](/newtech) is ShiroSU's own **native root implementation**,
> with a **WebUI-based management** design that gives it a more novel user experience

Beyond basic **privilege management** and **module management**, **ShiroSU Compat** provides many convenience features built on root implementation capabilities
