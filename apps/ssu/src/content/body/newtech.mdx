**ShiroSU NT** 是 **ShiroSU** 自己的**原生 root 实现**，提供了完整的**权能管理**与**模块系统**功能

> 与 <SiteLink site='compat'>**ShiroSU Compat**</SiteLink> 的定位不同，
> **ShiroSU NT** 侧重于提供自己的**独立 root 实现**，而不是像前者为其他 root 实现提供兼容适配

**ShiroSU NT** 在部分设计上与 <SiteLink site='compat'>**ShiroSU Compat**</SiteLink>
相互支持，并且提供了支持 **ShiroSU NT** 与其他 root 实现的**模块构建工具**
