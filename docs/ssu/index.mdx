**ShiroSU 系列** 致力于提供更易上手的 Android 使用方式，主要通过 root 相关功能实现更便利、更完整地使用

## 项目分化

[**ShiroSU NewTech**](https://shirosu.gal.tf/newtech) (简称 _SSU NT_，又称 _SSU ROOT_)
是 SSU 自己的 root 实现，是基于 `ramdisk` 注入实现的**纯用户态 root 实现**，采用 **WebUI** 实现 **root 管理**

[**ShiroSU Compat**](https://shirosu.gal.tf/compat) (简称 _SSU Compat_，又称 _SSU 管理器_)
是**兼容多种 root 实现**的 root 管理器，可以**管理模块与权能**

在规划上，它们是两个相对独立的项目（在部分设计上相互支持），但 SSU 就是通过这样的**双路线开发**实现覆盖面广且便利好用的

[**ShiroSU Utils**](https://shirosu.gal.tf/utils) (简称 _SUU_，中文名 _苏柚_) 是系列中的姊妹项目，具体可见下方简述

其他项目描述可见 [**ShiroSU 系列** 官网](https://shirosu.gal.tf/) 或 [**ShiroSU 系列** 关于](https://shirosu.gal.tf/about)

## 拓展软件

[**苏柚**](/suu) (简称 **SUU**) 是 **ShiroSU 系列** 中的姊妹项目

苏柚 主打**存储优化**功能，整体都着重于**更多功能使用**，在方方面面都提供一些小帮助

它**不局限于 root**，**普通用户权限**、**adb 权限**、**DeviceOwner 权限**
都可用来驱动部分功能，同时还有 **Xposed 注入** 功能，还可以通过 **Windows 版本**来体验更多内容
