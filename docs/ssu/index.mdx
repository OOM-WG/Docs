ShiroSU 致力于为用户提供更易上手的 root 使用方式，在一切便利的基础上通过各种功能完整地使用 root

## 项目分化

**ShiroSU NewTech** (简称 _SSU NT_，又称 _SSU ROOT_) 是 SSU 自己的 root 实现，
是基于 `ramdisk` 注入实现的**纯用户态 root 实现**，采用 **WebUI** 实现 **root 管理**

**ShiroSU Compat** (简称 _SSU Compat_，又称 _SSU 管理器_) 是**兼容多种 root 实现**的 root 管理器，可以**管理模块与权能**

在规划上，它们是两个相对独立的项目（在部分设计上相互支持），但 SSU 就是通过这样的**双路线开发**实现覆盖面广且便利好用的

## 拓展软件

[**苏柚** (简称 **SUU**)](/suu) 是 ShiroSU 的拓展软件，不过本质上它们是两个独立软件

苏柚 着重于**更多功能使用**，而不是 ShiroSU 这样着重于**基本的使用体验**

它**不局限于 root**，**普通用户权限**、**adb 权限**、**DeviceOwner 权限** 也可在 苏柚 使用，
同时还有 **Xposed 注入** 功能，
还可以通过 **Windows 版本**来体验更多内容
