### 有没有人知道这个怎么用?

> [NT](/ssu/nt) 作为原生 root 可安装至设备后通过 WebUI 使用，
> [Compat](/ssu/compat) 可作为第三方 root 管理器使用

### 如何将后端限制至仅本地可访问？

> 在设置中将后端监听 IP 改为 `127.0.0.1` 即可

### 为什么通过网页 fastboot 刷入无法使用？

> [WebUSB](https://developer.mozilla.org/en-US/docs/Web/API/WebUSB_API#browser_compatibility)
> 仅在 **Chromium 内核**的浏览器上可用

### 为什么默认密码填写设置里的序列号或者 `SSU-PASSWD` 无效？

> 大部分设备均有序列号，仅当明确知晓当前设备无序列号时才可使用回退密码 `SSU-PASSWD`
>
> <br />
> 部分机型在系统设置里的序列号并不准确，可通过电脑使用 `adb`/`fastboot` 二次确认

### 为什么电脑上无法连接手机 IP？

> 请注意是否误填为电脑本机 IP `127.0.0.1` 或电脑的局域网 IP，如果通过 adb 转发了端口才可直接使用本机 IP
>
> <br />
> 局域网连接需要确保电脑与手机处于同一局域网内，再查询手机在当前局域网内的 IP 才可连接，局域网 IP 通常以 `192.168` 开头

### 为什么部分浏览器无法连接后端？

> 部分浏览器例如 Firefox、Safari 默认拦截 `https`/`http` 混合协议，推荐使用 **Chromium 内核**的浏览器

### 为什么开启被隐藏权能的应用后无法连接后端？

> 检测到目标应用运行时会自动断开端口监听
>
> <br />
> 所以尽量不要对后台长期运行的应用隐藏权能，并且也不要对需要隐藏权能的应用允许自启动

### 为什么部分脚本无法执行，仅有在使用额外环境（例如 _MT终端扩展包_）时才可执行？

> 此类脚本可能涉及硬编码搜索 `busybox` 路径来使用系统环境不存在的命令
>
> <br />
> 所以此问题由脚本自身写法导致，没有办法解决

### 用户态 root 实现的实用性是否会逊于内核态 root 实现？

> 对于 root 实现而言，用户态与内核态的主要区别在于主动获取 root 权限的方式，尽管获取方式并不相同，但是结果总是相似的，差异并不大
>
> <br />
> 除此之外，例如 **模块系统** 等其他功能的主要运行逻辑并无差别
>
> <br />
> 并且用户态与内核态并不冲突，使用用户态 root
> 实现的同时也可以动态加载内核模块或是静态修改内核文件，同样可以继续使用基于内核态的功能

### 基于 WebUI 的管理方式是否需要让设备与外部服务器连接？

> 通过网页管理 root 是直接连接设备本身开放的后端服务，不需要任何外部服务器的参与
>
> <br />
> 只有通过浏览器访问 WebUI 来下载前端资源是必要的（相当于安装其他 root 实现的**管理器 APK**）
>
> <br />
> WebUI 本身也只是静态网页（_SSG_），网页内容均通过连接设备后直接展现
