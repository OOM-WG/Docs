ShiroSU Compat 在模块方面与 ShiroSU NT 有部分重合，具体可与 [SSU NT 开发文档](/ssu/nt/dev) 相互对照

<Tip>
  如果将 ShiroSU Compat 仅用于其他 root 实现的 root 管理器，那么模块标准应当以当前 root 实现为准，ShiroSU Compat
  **不会干涉**其他 root 实现的任何行为
  <></>
  但不依赖 root 实现的标准可以**额外再遵守** ShiroSU Compat 的标准，实现对 ShiroSU Compat 的专门适配
</Tip>

ShiroSU Compat 的特性主要基于 **Scheme**、**模块**，均为完全基于其自身的特性，**可在其他 root 实现上使用**
