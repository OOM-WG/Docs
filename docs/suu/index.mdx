<span>
  <Tooltip headline='苏柚' cta='若已安装，可在此打开' href='suu://'>
    [**苏柚**](https://utils.shirosu.my.id/) (简称 **SUU**)
  </Tooltip>{' '}
  是由 [回忆溢出工作组](https://oom-wg.dev/) 的开发组成员 [@梦璃酱](https://oom-wg.dev/developers) 发起的项目
  <></>原为仅有文件整理功能的 root 模块 **_Intelligent_**，后与核心成员 [@白彩恋](https://oom-wg.dev/developers)
  合作维护，转型为多功能软件
</span>

苏柚 旨在以 _普通权限_/_adb 权限_/_DeviceOwner 权限_/_root 权限_/_Xposed 注入_
全面地覆盖各类 Android 设备并加以 Windows 的辅助，提升玩机体验

## 特色功能

苏柚作为多功能软件，好用功能当然少不了！
